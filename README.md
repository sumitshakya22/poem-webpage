# Poem Web Page (Ozymandias)

A simple web page for the poem "Ozymandias" by Percy Bysshe Shelley, built using HTML and CSS.

## Features
- Styled heading and author name
- Centered poem text
- Hyperlink to the poem's Wikipedia page
- Comment text box

## Technologies Used
- HTML
- CSS
